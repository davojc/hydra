- Ruling: Task 12 Minor #1 (EDITOR path with spaces) folded into the fix round — Windows editors usually live under "Program Files" — cost if wrong: trivial
- Ruling: final Minor 3 (unrelated provider materialise failure blocks whoami/auth) left deferred — error carries a fix; changing materialise semantics is a design change better made with Plan 4's doctor — cost if wrong: whoami unusable until the other provider is fixed
- Ruling: final Minor 6 (rename normalises CRLF/BOM) left deferred — harmless — cost: diff noise in dotfiles repos
